    Fiabilité du codage

    Accord entre les deux moteurs de codage, Jev et Claude, sur les tweets qu'ils ont tous deux codés.

    Méthode

    Corpus. Tweets originaux publiés sur X par les comptes officiels des candidats déclarés, investis ou suivis, depuis le 1er septembre 2026. Les réponses et les reposts sont exclus. La collecte est quotidienne.

    Cadre. La grille s'inspire de l'approche socio-cognitive de Teun A. van Dijk. Elle code les macrostructures (le tweet parle-t-il d'écologie, à quel point, de quels thèmes), la position, le cadrage, le carré idéologique (valoriser « nous », dévaloriser « eux »), les acteurs désignés comme adversaires ou victimes, l'acte de discours et le registre. Le lexique marqué et les présupposés sont relevés pour la lecture qualitative.

    Codage. Chaque tweet est codé par Jev, un modèle de décision qui renvoie pour chaque variable une probabilité calibrée. Claude, un modèle de langage, sert de second codeur à la demande : sur les décisions incertaines de Jev, sur un échantillon de validation, et pour le relevé du lexique et des implicites. La valeur affichée est celle de Jev, sauf décision incertaine recodée par Claude.

    Limites. X n'est qu'un fragment du discours de campagne, souvent écrit par des équipes. Les modèles peuvent se tromper, notamment sur l'ironie et les tweets très courts. Les pourcentages calculés sur moins de 20 tweets sont fragiles. L'accord entre deux modèles mesure leur convergence, pas la justesse du codage : une validation par codeurs humains est prévue.

    Livre de codes

    Données : API X. Codage : Jev (TypeSafe) et Claude (Anthropic). Les tweets restent la propriété de leurs auteurs ; chaque citation renvoie au message original.
